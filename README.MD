# Monnify Payroll System

Este proyecto es una implementación del sistema de nómina utilizando Express y Monnify con trabajos en segundo plano, basado en el tutorial de freeCodeCamp.

## Tutorial de Referencia

Para más detalles sobre cómo construir este sistema, consulta el tutorial completo en:  
[Build a Payroll System with Express and Monnify using Background Jobs](https://www.freecodecamp.org/news/build-a-payroll-system-with-express-and-monnify-using-background-jobs/)

## Instalación

1. Clona el repositorio.
2. Instala las dependencias: `npm install`
3. Configura las variables de entorno necesarias.
4. Ejecuta el servidor: `npm start`
